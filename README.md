## Um roteiro para conhecer meu trabalho

- **Full stack e regras de negócio:** comece pelo Barbershop. O README aponta os arquivos de autenticação, disponibilidade e testes de reservas concorrentes.
- **Integrações e experiência de uso:** explore o News. A demonstração usa notícias fictícias e traduções de exemplo; as integrações reais exigem configuração no servidor.
- **Interfaces e dados:** compare Finance, Utilidades e Clima. Cada projeto explica suas fontes, configuração e limites no README.

As demonstrações são projetos de portfólio. No Finance, o conversor usa taxas fictícias identificadas; no Barbershop, serviços e profissionais são fictícios e a API pode demorar no primeiro acesso.

## Tecnologias presentes nos projetos

**Interfaces:** React, Next.js, TypeScript, JavaScript, CSS e Tailwind CSS.  
**Servidor e dados:** Node.js, Express, MongoDB e APIs externas.  
**Qualidade e entrega:** testes automatizados nos projetos Barbershop e News, GitHub Actions no Barbershop e publicação na Vercel.

Os repositórios incluem instruções para execução e detalhes das decisões técnicas. A autoria e os créditos estão documentados em cada projeto.
